# Full-Stack Spring Boot & Angular

Projet fil rouge du cours full-stack : une application de gestion de produits et catégories.

## Stack technique
- **Backend** : Java 21, Spring Boot, Spring Data JPA, Hibernate, Lombok, MySQL
- **Frontend** : Angular (à venir)

## Structure
- `backend/` — API Spring Boot

## Progression
-  Atelier 01 : couches Modèle, Persistance (Repository) et Service, tests CRUD
-  Atelier 02 : association Categorie-Produit (OneToMany/ManyToOne), Lombok, requêtes dérivées et JPQL, tri
-  Atelier 03 : à venir
